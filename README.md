# Vimanaweb

Разработка модулей и доработка интернет-магазинов на **OkayCMS**.

## Чем занимаюсь

- Разработка модулей под задачи интернет-магазина.
- Доработка карточки товара, каталога и оформления заказа.
- Интеграция служб доставки.
- Настройка шаблонов и исправление ошибок.

## Проекты для OkayCMS

| Модуль | Назначение |
|---|---|
| **MinOrder** | Ограничение минимальной суммы заказа |
| **ProductNote** | Примечание покупателя к товару при заказе |
| **Укрпочта** | Выбор отделения из локального справочника |
| **Meest** | Выбор населённого пункта и отделения доставки |
